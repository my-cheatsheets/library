# My CheatSheets library

Ready-made cheat sheets for [My CheatSheets](https://my-cheatsheets.com). Browse them at [my-cheatsheets.com/library](https://my-cheatsheets.com/library), add one to your own sheets, then read it in the Android app, even offline, or change it to suit you.

Every sheet is checked by a person before the website shows it.

| Sheet | What it covers |
|---|---|
| [Capital Cities & Flags](sheets/capital-cities-and-flags/sheet.json) | The capital of each of 197 countries, with its flag: the 193 UN members, the 2 UN observer states, Kosovo and Taiwan. |
| [MacBook Pro (Apple silicon)](sheets/macbook-pro-apple-silicon/sheet.json) | Keyboard shortcuts, trackpad and Magic Mouse gestures on a MacBook Pro with an M-series chip, running macOS Tahoe 26 or later. |

Sheets about a company's products aren't made or endorsed by that company.

## Found a mistake?

[Open an issue](https://github.com/my-cheatsheets/library/issues/new/choose), or email support@my-cheatsheets.com. Say which sheet and entry, what's wrong, and where the right answer can be checked.

## Suggest or add a sheet

See [CONTRIBUTING.md](CONTRIBUTING.md). You can suggest a sheet in an issue, or add one yourself with a pull request.

## How it's published

Each change to `main` is checked, then published to `https://library.my-cheatsheets.com/v1/`: an `index.json` listing every sheet, the sheets themselves, and every version each has had, from `main`'s history. The website picks up changes by the next morning.
